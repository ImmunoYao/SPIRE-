SPIRE (Synovial Pathway Immune-subpopulation RA-resemblance Evaluation) is a standardized, single-cell transcriptomics-based framework for quantifying how faithfully a mouse arthritis model recapitulates the pathway-activity landscape of human rheumatoid arthritis synovium. Rather than comparing absolute pathway scores across species — which are confounded by inherent differences in gene expression magnitude, ortholog coverage, and sequencing depth — SPIRE compares the relative organization of Hallmark pathway activities across matched synovial cell subpopulations (macrophages, monocytes, dendritic cells, T cells, and fibroblast-like synoviocytes) using within-species z-score normalization and Spearman rank correlation. The framework operates exclusively on disease-state data, eliminating the baseline asymmetry that arises when human studies use osteoarthritic synovium as control while mouse studies use truly healthy tissue. SPIRE evaluates each model across multiple dimensions — including cell-type-specific correlation strength, self-match ranking accuracy, global structural significance, sensitivity to pathway composition, and pathway-level concordance — without collapsing these into a single composite score, thereby allowing researchers to assess which aspects of human RA pathology a given model is best suited to investigate. Applied to four established mouse arthritis models spanning different genetic backgrounds and induction mechanisms, SPIRE provides a reproducible, pathway-database-agnostic evaluation standard that can be directly extended to any future model with synovial single-cell RNA-seq data.
